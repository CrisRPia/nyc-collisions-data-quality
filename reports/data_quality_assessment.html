Data quality assessment against DAMA-DMBOK2

NYC Motor Vehicle Collisions — Crashes · 2025 · 85,559 records · 29 published fields

The snapshot supports a meaningful quality-improvement project. Its main demonstrated limitation for the selected use is incomplete geographic attribution. Strong structural conformance does not establish real-world accuracy.

Assessment scope. Annual 2025 borough-level road-safety analysis of police-reported crashes, with geographic and vehicle-category summaries. This is an analyst-defined use case. Requiredness and acceptability targets have not been approved by NYPD or a business stakeholder. Raw records remain unchanged; proposed recoveries are not an achieved after-state.

1. Method and DMBOK2 basis

Chapter 13 defines quality relative to consumer needs and critical data (printed p. 457). It presents the DAMA UK six core dimensions on p. 460 while also discussing other frameworks. Table 29, pp. 461–462, distinguishes validity, accuracy, consistency, requiredness, uniqueness and timing. Rules are linked to purpose, scoped denominators and analytical impact (pp. 467–468, 478–479). Measurements use conforming or exception counts over applicable observations (pp. 482–483). A threshold in a book example is not a universal pass mark.

Book pagination in this attachment: PDF page = printed page + 4. Main references: printed pp. 457, 460–463, 467–468, 476–486. No combined quality score is calculated. Counts can overlap; denominators can be records, populated values or cells. Unknown/not measurable remains unknown.

3. Geographic recovery pilot

Of 7,100 missing boroughs, 6,573 have a unique polygon-interior candidate outside the approximate boundary band. If accepted after validation, 527 would remain unresolved. These are candidate derivations, not corrections already applied.

On 75,393 eligible records that already supply a borough, the reference lookup agrees on 75,297 (99.873%). The 96 disagreements require review. This is observed agreement, not a ground-truth accuracy estimate. The land-only polygon version may differ from the 2025 shoreline; water/bridge points and near-boundary points need special handling. The exclusion band is 0.0003 degrees, not a guaranteed metric buffer.

Source borough missingness: 8.30%.

5. Interpretation of the issues raised during inspection

  • Numeric strings: source metadata declares numeric columns as Number. Socrata serializes these values as JSON strings to preserve precision. Validate their logical domains and parse at ingestion; do not count every string as erroneous data.
  • Repeated location: the nested location repeats coordinates and its human_address is empty throughout. Agreement is a passing consistency check. Removing redundant location from a curated analytical table is schema simplification.
  • Different vehicle spellings: the explicit candidate rule chooses the most frequent exact spelling across all five vehicle slots within each strip/casefold group. There are 149,131 populated vehicle cells and 571 nonmodal cells on 560 records, across 102 multi-spelling groups. This is not an official vehicle taxonomy; “PK”, “AMB” and other different words are left alone.
  • Person/subtype totals: equality with pedestrian+cyclist+motorist is not established by the source definition. Differences require semantic review; do not overwrite totals or infer that source totals are necessarily wrong.

8. Evidence, provenance and reproducibility

Run uv run analysis/analyze_quality.py from the project, or use the script's absolute path. The script uses local source snapshots, NumPy and matplotlib, makes no network calls and checks that the raw JSON hash remains unchanged. Outputs include the JSON assessment, field profile, rule scorecard, issue register and proposed borough/spelling mappings. The raw data is never overwritten.

Limits

  • No blanket field-completeness score: optional/conditional vehicle slots, addresses, factors and ZIP are profiled without declaring every blank erroneous.
  • No composite score or universal acceptability threshold. Structural domains are explicit; operational targets require stakeholder agreement.
  • No original event/coordinate/count accuracy audit, no independently reconciled total event population, no operational latency measurement.
  • Current land-only reference polygons are compared with 2025 events, with an approximate boundary exclusion. Reference disagreement is a review flag.
  • Recovery candidates are conditional proposals; no cleaned dataset or claimed achieved after-score is produced.
  • Issue counts overlap and mix records/cells; do not add them to estimate unique defective records.
  • No root cause is established solely from profiling; source capture, coding, geocoding and extraction hypotheses need owner review.
